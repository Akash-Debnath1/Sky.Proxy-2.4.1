Как добавляем?

Вставьте прокси — по одному в строке

Формат определяется сам: ip:port, ip:port@логин:пароль, ip:port:логин:пароль, логин:пароль@ip:port.

Также понимаются ссылки вида http://user:pass@ip:port и адреса по имени: proxy.example.com:8080

Протокол

Тип определяется по схеме из строки или по порту. Для SOCKS5 Chrome не передаёт логин и пароль — подойдёт прокси с авторизацией по IP.

Страну можно отметить вручную в списке. У прокси из вашего аккаунта она подставится сама.

Ключ API

Покажет прокси из вашего аккаунта — выберете, какие добавить. У добавленных будут сами обновляться сроки и страна. Ключ — в кабинете, раздел «API».

Автоматически подтягиваются только серверные прокси. Ключ от отдельного заказа покажет только его адреса — для всех используйте общий ключ.

Получаем список прокси…

По этому ключу серверных прокси не найдено. Мобильные и резидентские прокси пока не подтягиваются автоматически — их можно добавить вручную на вкладке «Строкой» или «Полями».

Аккаунт

Расширение разбирает четыре записи — по одному прокси в строке, добавятся все сразу. Клик по формату копирует его как образец.

  1. Войдите в кабинет на proxys.io
  2. Откройте раздел API и скопируйте ключ
  3. Вставьте его во вкладке «По ключу»
  4. Сроки обновятся сами. Новые прокси из аккаунта нужно добавить самому.

У загруженных так прокси видно страну и срок аренды — добавленные вручную приходят без этих данных.

По ключу подтягиваются только серверные прокси. Мобильные и резидентские добавляются вручную: возьмите в кабинете строку с адресом и вставьте на вкладке «Строкой». Адрес бывает числовым — ip:порт:логин:пароль, — а бывает именем хоста: proxy.example.com:8080. Расширение понимает оба.

В кабинете есть общий ключ на все прокси и отдельные ключи на каждый заказ. Ключ от заказа покажет только его адреса. Для полного списка возьмите общий ключ в разделе «API».

По умолчанию расширения не работают в режиме инкогнито, и прокси там не применяется — сайты увидят ваш настоящий адрес. Чтобы включить, скопируйте адрес настроек кнопкой ниже и вставьте в адресную строку браузера.

В окне инкогнито расширение не работает — сайты там видят ваш настоящий адрес. Разрешите его в настройках расширения.

  1. Сверьте логин и пароль: чаще всего дело в них
  2. Проверьте, не истёк ли срок аренды адреса
  3. Если ваш провайдер прокси ограничивает доступ по IP — обновите свой адрес в его кабинете

Реальный адрес обычно утекает через WebRTC — браузер устанавливает прямое соединение мимо прокси. Включите «Блокировать WebRTC» в настройках и перезагрузите вкладку.

Вторая причина — DNS: провайдер видит запросы, даже когда трафик идёт через прокси. Помогает DNS-over-HTTPS в настройках браузера.

Нажмите кнопку — расширение соберёт техническую информацию и скопирует её. Вставьте текст в обращение в поддержку, это сильно ускорит разбор. Логины, пароли и ключ API в неё не попадают.

Не нашли ответ? Поддержка на proxys.io отвечает в течение пары минут.
